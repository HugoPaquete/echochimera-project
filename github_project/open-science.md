# Open science

## Position

ECHOCHIMERA aims to follow the spirit of FCT open-science practices:
public concepts, methods, evaluation and research outputs, while
protecting authorship and control over the software implementation.

This page is a project statement, not a legal interpretation of a funding
contract. Confirm obligations with the FCT and the University of Aveiro
research office.

## Public layer

- concept and research question;
- conceptual architecture;
- musical and performance theory;
- evaluation summary;
- paper/preprint;
- figures and interface documentation;
- credits, funding and citation.

## Private layer

- source code;
- implementation details;
- executable;
- user data and recordings;
- build artefacts.

## Access for review

The source can be made available to reviewers or research collaborators
under a confidentiality agreement. This supports verification without
making the implementation public.

## FAIR principles

| Principle | Implementation |
|---|---|
| Findable | public project page, citation metadata, keywords |
| Accessible | open documentation; source by request |
| Interoperable | MIDI, standard notation and documented concepts |
| Reusable | public theory and method; licence for documentation |

## Preservation

Recommended:

- deposit the paper in an institutional or Zenodo/OSF repository with a
  DOI;
- keep a versioned documentation release;
- record the public release date and version;
- keep the source and executable in a controlled archive.

## Limits

The public layer does not claim to reproduce the software. It documents
the concept, method and evaluation so that the work can be discussed,
cited and assessed.
