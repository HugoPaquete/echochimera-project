# Access policy

## Public

This repository publishes:

- concept;
- architecture at a conceptual level;
- musical theory;
- performance theory;
- public evaluation;
- paper;
- figures and screenshots;
- credits, funding and citation metadata.

## Private

The following are **not** distributed publicly:

- source code;
- implementation formulae;
- internal class structure;
- build artefacts;
- executable;
- user configuration;
- session recordings;
- backups.

## Why

The project is both an artistic instrument and a research object. Public
documentation supports knowledge exchange; the source remains private to
protect authorship, control versions and avoid unverified forks.

## Research access

Source access for peer review, research collaboration or artistic
residency is available by written request, under a confidentiality
agreement and without redistribution rights.

Contact: <https://www.hugopaquete.com>

## What can be reproduced publicly

- conceptual architecture;
- musical model;
- evaluation claims;
- figures;
- public paper;
- interface behaviour from screenshots.

## What requires access

- exact implementation;
- parameter calculations;
- MIDI scheduling internals;
- build pipeline;
- executable.

## No implied licence

Nothing in this repository grants a licence to the source code or the
executable. See [NOTICE](NOTICE.md) and [Licence](LICENSE-DOCS.md).
